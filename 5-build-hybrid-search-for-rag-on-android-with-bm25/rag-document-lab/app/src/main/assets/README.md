# EmbeddingGemma model

Download the EmbeddingGemma `.task` model bundle and add it to this directory as:

```text
embedding_gemma.task
```

The model is intentionally excluded from Git because of its size and license terms.

The app expects the MediaPipe Text Embedder task bundle used by the Episode 3 final project. It loads the model from the APK assets and keeps `.task` files uncompressed.
